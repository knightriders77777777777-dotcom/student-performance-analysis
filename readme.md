# Student Performance Analysis Using Python

## Project Description
This project analyses student marks using Python and displays their academic performance.

## Objectives
- Calculate average marks.
- Identify the highest marks.
- Classify students as Pass or Fail.
- Visualize student marks using a bar graph.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Project File
- student_analysis.py

## Sample Results
- Average Marks: 72.4
- Highest Marks: 92
- Pass students: 4
- Fail students: 1

## How to Run
1. Install Python.
2. Install required libraries:
   pip install pandas matplotlib
3. Run:
   py student_analysis.py

## Conclusion
This project demonstrates basic student performance analysis and data visualization using Python.
